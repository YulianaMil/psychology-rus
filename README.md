# psychology-rus
# Психология на русском — открытый каталог ресурсов

Открытый, редактируемый справочник русскоязычных материалов для психологов:
курсы, учебники, методики, журналы, инструменты. Собирается сообществом.

> Правило каталога: только проверенные ссылки. Каждая позиция проходит по одному пункту — «я этим пользовалась / пользовался» или «рекомендовано проверенным источником».

---

## 1. Статистика и анализ данных

- **«Анализ данных и статистика в R» — Иван Поздняков** — бесплатная онлайн-книга: R с нуля, tidyverse, ggplot2, статистические тесты, линейные модели. Код книги лежит на GitHub. <https://pozdniakov.github.io/tidy_stats/>
- **«Основы статистики для психологов»** — учебник по SPSS, Jamovi и R с примерами на данных психологических исследований (зеркало в зоне .ru). <https://handbook.mathpsy.ru/>
- **Бесплатный курс «Обработка и анализ данных в SPSS» — Академия НАФИ** — 13 лекций, открытые базы данных исследований, для начинающих. <https://nafi.ru/academy/free-seminars/kurs-spss/>
- **YouTube: НСО ИП РГГУ** — лекции по работе в SPSS от Института психологии им. Л. С. Выготского РГГУ. <https://www.youtube.com/watch?v=3e8w16Y1j34>

## 2. Психодиагностика: где искать методики легально

- **Реестр психодиагностического инструментария для педагогов-психологов — МГППУ / Минпросвещения** — официальный открытый реестр: методика, измеряемый конструкт, возрастная группа, источник публикации. <https://mgppu.ru/project/473/info/7293>
- **Электронная библиотека МГППУ (psychlib.ru)** — книги и материалы по психодиагностике, есть версия для незрячих и слабовидящих. <https://psychlib.ru/?s=rub&cat=1.3.2>
- **PsyTests (psytests.org)** — более 5000 тестов онлайн (3500+ профессиональных), бесплатно и анонимно, с описанием методик. Результаты предназначены для интерпретации специалистом. <https://psytests.org/>
- **Тесты на b17.ru** — большая коллекция русскоязычных опросников с онлайн-прохождением (HADS, GAD-7, PCL-5, AUDIT и др.). <https://www.b17.ru/tests/>

> Важно: коммерческие методики (например, MMPI-2) нельзя копировать целиком — используйте официальные адаптации и покупайте лицензионные версии. В каталоге — только описания и ссылки.

## 3. Статьи и журналы на русском

- **КиберЛенинка** — крупнейшая открытая библиотека русскоязычных научных статей, включая психологию. <https://cyberleninka.ru/>
- **psyjournals.ru** — «Психологическая наука и образование», «Клиническая и специальная психология», «Консультативная психология и психотерапия» и другие журналы МГППУ — полный текст бесплатно. <https://psyjournals.ru/>

## Как внести вклад

1. Нашли полезный ресурс на русском — откройте Issue или пришлите Pull Request.
2. Формат записи: **Название** — одна строка, что это и для кого. Ссылка.
3. Ресурсы с недоступными ссылками периодически чистятся.
